## About

**Phishing: Advanced Threat Analysis** is Volume 3 of the *Don't Get Hooked!* series — built for security professionals operating at the cutting edge of offensive and defensive phishing security. No simplification. Full attack-defence symmetry across 10 modules.

Rendered in a deep purple gradient with JetBrains Mono, code blocks, system architecture layouts, and data tables.

---

## 📖 What's Inside

| Module | Title | What You Learn |
|---|---|---|
| 01 | AiTM Proxy Architecture | Evilginx2/Modlishka, session cookie interception, CAE countermeasures, FIDO2 origin binding |
| 02 | Adversarial ML Evasion | Black-box probing, gradient estimation, surrogate model attacks, model poisoning |
| 03 | Infrastructure Graph Analysis | GNNs, DiGraph construction, passive DNS correlation, Neo4j implementation |
| 04 | LLM Spear Phishing | OSINT-to-phish pipeline, LLM prompt engineering, perplexity-based detection |
| 05 | DNSSEC & RPKI Hardening | Chain-of-trust validation, Registry Lock, BGP hijacking defence, RIPE monitoring |
| 06 | Sigma Detection Rules | ATT&CK mapping, domain age enrichment, KQL/SPL/ESQL deployment |
| 07 | Zero Trust Email | Time-of-click scanning, CAE, BIMI+VMC, delayed payload defence |
| 08 | Red Team Simulation | GoPhish methodology, campaign metrics, just-in-time training design |
| 09 | SOAR Automation | T+0 to T+60 playbook, STIX/TAXII IOC sharing, org-wide quarantine |
| 10 | Research Frontiers | LLM detection accuracy, AI-DGA evasion, post-quantum auth, federated CTI |
